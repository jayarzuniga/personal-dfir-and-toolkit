## Forensics Processes

Forensics processes define how analysts identify, preserve, collect, examine, and report digital evidence. A consistent process helps maintain evidence integrity, prioritize volatile data, and guide incident responders through structured forensic collection and analysis.

These references are useful for live response planning, evidence handling, Windows artifact review, and post-incident reporting.

### Objectives of Forensics Process Analysis

* Preserve evidence integrity during acquisition and examination
* Prioritize volatile artifacts during live response
* Follow recognized forensic and incident response guidance
* Identify relevant Windows forensic artifacts during investigations
* Support defensible documentation and reporting

### Common Information Analyzed

* Evidence collection order and volatility considerations
* Disk, memory, registry, event log, and filesystem artifacts
* Windows forensic artifact locations and meanings
* Incident response and forensic examination phases
* File system structures and file signature references
