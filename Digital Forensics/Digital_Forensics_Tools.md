## Digital Forensics Tools

Digital forensics tools support evidence acquisition, artifact parsing, timeline creation, memory analysis, disk examination, and triage collection. Analysts use them to preserve source evidence, extract meaningful artifacts, and reconstruct activity across endpoints and storage media.

These tools are commonly used in incident response, malware investigations, endpoint compromise reviews, and forensic lab analysis.

### Objectives of Digital Forensics Tool Analysis

* Acquire disk, memory, and volatile evidence for examination
* Parse operating system artifacts into analyst-friendly output
* Reconstruct user, process, file, and network activity timelines
* Examine file systems, deleted files, and storage metadata
* Support repeatable triage and deeper forensic workflows

### Common Information Analyzed

* Disk images, memory images, and triage collections
* Windows registry, prefetch, event log, shellbag, and shortcut artifacts
* File system metadata and deleted file records
* Process, network, and memory-resident artifacts
* Timeline events from multiple forensic data sources
